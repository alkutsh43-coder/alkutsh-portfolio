# كتالوج الإنتاج المصغر - Ahmed Maher (Production Portfolio)

موقع بورتفوليو تفاعلي عالي الاحترافية مصمم خصيصاً بنمط **Technical Editorial** ليخاطب مدراء المطابع وشركات التغليف والإنتاج في المملكة العربية السعودية، مجسداً دورة حياة المنتج المطبوع كاملة:
**Brief → Concept → Design → Prepress → Production → Final Product**.

---

## 🌟 الميزات والمكونات الرئيسية

1. **الهوية البصرية والنمط التقني (Technical Editorial)**:
   - شبكة هندسية دقيقة (Grid System) ومساحات واسعة.
   - خط **Monospace** مخصص لكتل المواصفات التقنية (المقاسات، الجراماج، أنظمة الألوان).
   - علامات تسجيل الطباعة الحية (`⌖` Registration Marks) وشريط معايرة الألوان CMYK + Spot.

2. **عارض Prepress التفاعلي (Interactive Prepress Inspector)**:
   - ميزة تفاعلية نوعية لفحص طبقات الملف الطباعي:
     - **Cut Lines**: خطوط القص لماكينات التكسير بلون أحمر ماجنتا صلب.
     - **Crease Lines**: خطوط الريجة والثني بلون أزرق سيان مقطع.
     - **Foil Plate**: قناع بصمة الذهب بتقنية Overprint.
     - **Bleed Boundary**: زوائد الطباعة بمقدار +4.0 مم.
   - شريحة مقارنة تفاعلية (Before / After Split Slider).

3. **الأعمال المختارة بالطبقات الثلاث (10 دراسات حالة)**:
   - **الطبقة الأولى**: علب التغليف الصلبة (Rigid Boxes)، الهويات الورقية الفاخرة بوزن 600 جرام، واستيكرات الـ UV DTF الصناعية.
   - **الطبقة الثانية**: الكتالوجات متعددة الصفحات (160 صفحة) بحسابات الزحف (Creep)، لافتات المعارض الضخمة (12 متراً)، ودروع الأكريليك وخشب الجوز بالليزر.
   - **الطبقة الثالثة**: كروت الدعوة بالكبس الغائر (Blind Deboss)، طباعة الملابس بالسلك سكرين المفصول، والدفاتر التنفيذية المجلدة بالجلد الحراري.
   - **كتلة مواصفات موحدة (Spec Block)** لكل مشروع: `المقاس | نوع الخامة والجراماج | نظام الألوان | نوع التشطيب | تقنية الطباعة`.

4. **مصفوفة عقلية الإنتاج (Production Knowledge Matrix)**:
   - مقارنة مباشرة بين المصمم العادي ومصمم الإنتاج (Total Area Coverage, Bleed, Rich Black 100K, Caliper, PDF/X).

5. **دعم ثنائي اللغة كامل (عربي RTL / English LTR)** مع زر تبديل فوري.
6. **الجاهزية لسوق العمل السعودي**: تأكيد الاستعداد الفوري للانتقال والعمل في الرياض وجدة والشرقية.
7. **أدوات التواصل السريع**: زر محادثة واتساب مباشر، إيميل، رمز QR مدمج، وإمكانية طباعة وتصدير الدليل كـ PDF.

## 🚀 طريقة التشغيل محلياً

```bash
# تثبيت الحزم (إذا لم تكن مثبتة)
npm install

# تشغيل خادم التطوير المحلي
npm run dev
```

افتح الرابط الظاهر في الطرفية (عادة: `http://localhost:5173`) للتصفح فوراً.

---

## 📦 التجهيز للنشر (Production Build)

```bash
npm run build
```
سينتج مجلد `dist` الجاهز للرفع على أي استضافة (Vercel, Netlify, GitHub Pages, Hostinger, أو خادم محلي).

## ✏️ تعديل وإضافة المشاريع والبيانات الشخصية

كافة نصوص ومشاريع البورتفوليو موجودة بشكل منظم في ملف واحد:
`src/data/portfolioData.js`

- لتعديل رقم الواتساب أو الإيميل: عدّل قسم `meta.contact`.
- لتعديل أو استبدال صور المشاريع: ضع روابط صورك الحقيقية في خاصية `imageUrl` لكل مشروع.
